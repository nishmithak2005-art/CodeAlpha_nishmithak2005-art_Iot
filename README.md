Task 1 – Research Report: IoT in Industrial Automation

This task presents a research report on the application of Internet of Things (IoT) in Industrial Automation. It explains how IoT technology, sensors, and connected devices can be used to monitor industrial processes, improve efficiency, reduce downtime, and support better decision-making.

Task 2 – Sensor-Based Simulation

This task demonstrates a basic IoT system using Tinkercad and Arduino UNO. The simulation demonstrates LED control using Arduino programming.

The LED is turned ON for 1 second and OFF for 1 second continuously.

Components and Tools Used:

- Arduino UNO
- LED
- Resistor
- Breadboard
- Jumper wires
- Tinkercad
- Arduino Programming
- PIR Sensor

Submission:

- Simulation screenshots
- Arduino code
- Code explanation
